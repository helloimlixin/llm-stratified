\section*{Thesis}

Dense vision representations are not well summarized by a single intrinsic-dimension estimate. Frozen patch-token spaces have local geometric regimes that vary by model, image region, dataset, and radius scale. The paper tests this with local volume scaling, corrected fiber-bundle slope-increase tests, same-image locality, raw-patch sparse reconstruction burden, and patch-token distance diagnostics.

\section*{Current Model Set}

\begin{itemize}[leftmargin=1.5em]
\item DINOv3-H+ and DINOv3-L as self-supervised dense feature baselines.
\item SAM-H as a segmentation-oriented encoder with COCO mask-preview context.
\item SigLIP2-B and AIMv2-L as modern multimodal or vision-first frozen encoders.
\item VAR-d30 as an auxiliary autoregressive visual-token control, not as a matched encoder baseline.
\end{itemize}

\section*{Data}

\begin{itemize}[leftmargin=1.5em]
\item Main case study: image-aligned COCO subsets at $224\times224$.
\item Stress tests: STL10, DTD, and EuroSAT.
\item Patch-token grids are kept complete per selected image so diagnostics can be projected back to image space.
\end{itemize}

\section*{Diagnostics}

\begin{itemize}[leftmargin=1.5em]
\item Local dimension from log-neighbor-count versus log-radius slopes.
\item Fiber-bundle violations from corrected slope increases across adjacent radius windows.
\item Same-image nearest-neighbor locality to understand what the local neighborhoods are sampling.
\item Local sparse raw-patch complexity with one OMP/PCA dictionary per token neighborhood.
\item Patch-token distance agreement to compare raw RGB patch geometry with learned feature geometry.
\item VAR generation-side entropy, NLL, and branch-sampling controls.
\end{itemize}

\section*{Core Empirical Claims}

\begin{itemize}[leftmargin=1.5em]
\item DINOv3 and SAM can have similar median local dimensions while differing in locality, corrected slope changes, and sparse reconstruction burden.
\item SigLIP2 and AIMv2 move the comparison into higher-dimensional local regimes without collapsing the sparse-complexity story into a simple model ranking.
\item Cross-dataset probes show that domain shift changes which model and diagnostic is most stressed.
\item Sparse complexity, local dimension, generic change points, and corrected fiber violations are separate signals.
\item VAR gives a useful caution: generation uncertainty aligns more clearly with broad local dimension than with corrected fiber violations in the current slice.
\end{itemize}
