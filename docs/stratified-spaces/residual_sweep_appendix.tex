\section{Residual-Threshold Sweep Visualizations}
\label{app:residual-sweep-visualizations}

This appendix gives the complete visual output for the high-capacity fixed-$k=128$ sparse dictionary residual-threshold sweep. The main text uses $\tau=0.30$ because it preserves regional contrast while avoiding the overly permissive look of very loose residual targets. Here we include every threshold used in the DINOv3-H+/SAM-H sweep, together with the detailed probe dashboard for each model and threshold. All residual-sweep models use 128 local PCA dictionary atoms with maximum OMP sparsity 64. We also include the corresponding SigLIP2-B/AIMv2-L sweep summaries and their $\tau=0.30$ paper-facing heatmaps.
