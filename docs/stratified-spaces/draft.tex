\begin{abstract}
We test whether dense vision representations are better described by locally stratified geometry than by one global manifold dimension. Building on the fiber-bundle volume-growth test of \citet{robinson2025token}, we analyze frozen DINOv3, SAM, SigLIP2, and AIMv2 patch-token clouds on \dataset{COCO}, with \dataset{STL10}, \dataset{DTD}, and \dataset{EuroSAT} stress tests and an auxiliary VAR-d30 generation probe. For each token cloud, we estimate local dimension, corrected slope-increase violations of the fiber-bundle null, same-image locality, and a raw-patch sparse reconstruction burden using OMP; because each token maps back to an image patch, all diagnostics can be inspected spatially. Across models and datasets, local dimension, violation rate, locality, and sparse complexity separate from one another. DINOv3 is highly image-local, SAM is especially sensitive on segmentation-like and out-of-domain structure, and SigLIP2/AIMv2 occupy higher-dimensional local regimes with different sparse-complexity profiles. The main conclusion is simple: modern dense vision spaces contain heterogeneous local structure that a single intrinsic-dimension estimate hides.
\end{abstract}

\section{Introduction}
The \emph{manifold hypothesis} says that high-dimensional data concentrate near a much lower-dimensional set. It is a useful organizing idea, but modern representation spaces often need a more local description. One global intrinsic-dimension estimate can hide neighborhoods whose scaling behavior, effective dimension, or visual content changes from point to point \citep{loaiza-ganem2024deep,levina2005maximum,facco2017estimating,pope2021intrinsic,tempczyk2022lidl,tempczyk2026benchmarks}.

We therefore treat the manifold hypothesis as a local statistical null rather than as a global slogan. Around each anchor, a regular local model predicts that empirical ball volume should grow like a stable power law in radius, with only the allowed flattening captured by the fiber-bundle formulation. The test asks a directional question: after multiple-testing correction, does a later radius window grow faster than an earlier one? A positive answer marks a local failure of the tested regular model, not a claim that the entire representation is non-manifold.

Recent work on language-token embeddings sharpens this local view: compare each token's log-volume/log-radius curve with a permissive fiber-bundle null, and flag statistically significant slope increases as violations of that null \citep{robinson2025token}. The point is not merely that tokens are discrete. It is that learned neighborhoods can fail even a smooth local model. This paper asks the analogous question for dense vision representations.

Vision gives a cleaner observational handle than a vocabulary table. A transformer or segmentation encoder produces hundreds of patch tokens per image, and each token remains tied to a visible region: an object interior, boundary, texture, occlusion, or background transition. This makes the sampling denser: one image supplies a complete grid of nearby anchors that share scene context while varying in local visual content, so a small aligned image set yields thousands of spatially interpretable local neighborhoods. We can therefore estimate local geometry in feature space and project the result back to the image. That spatial link lets us ask not only whether a representation is locally regular, but where the irregularities occur and whether the corresponding raw patches are visually simple or complex.

We study frozen DINOv3, SAM, SigLIP2, and AIMv2 checkpoints on image-aligned \dataset{COCO} subsets \citep{simeoni2025dinov3,kirillov2023segment,tschannen2025siglip2,elnouby2024aimv2,lin2014microsoft}. We add \dataset{STL10}, \dataset{DTD}, and \dataset{EuroSAT} as domain shifts, and include VAR-d30 as an auxiliary autoregressive vision-token probe \citep{tian2024visual}. The claim is deliberately local and diagnostic: dense vision representations are not well summarized by one global dimension number. Their patch-token geometry is better treated as stratified, with local scaling and reconstruction complexity varying across image regions, models, and datasets.

\paragraph{Contributions.}
\begin{itemize}[leftmargin=1.5em]
\item We adapt the fiber-bundle volume-growth test of \citet{robinson2025token} to dense vision patch-token clouds.
\item We evaluate frozen DINOv3, SAM, SigLIP2, AIMv2, and VAR-d30 spaces on \dataset{COCO}, with stress tests on \dataset{STL10}, \dataset{DTD}, and \dataset{EuroSAT}.
\item We project local dimension, corrected slope-increase violations, same-image locality, and sparse raw-patch reconstruction burden back to image patches.
\item We show that these diagnostics separate: global dimension is a poor summary, and patch-projected geometry exposes model- and region-specific stratification.
\end{itemize}

\section{Method}
\paragraph{Overview.}
The unit of analysis is a spatial patch token. For each frozen model, an image yields token vectors $z_i$ and corresponding raw RGB patches $x_i$. We use this pairing for three diagnostics: local dimension from neighbor-count growth, fiber-bundle violations from forbidden slope increases in the same volume curve, and sparse raw-patch complexity from a local OMP dictionary. These diagnostics are intentionally separate. Local dimension measures feature-space volume growth; fiber violations measure scale changes in that growth; sparse complexity measures visible variation inside the token neighborhood.

\paragraph{Geometric null.}
Let $Z=\{z_1,\ldots,z_n\}\subset \R^\ell$ be the frozen patch-token cloud. The fiber-bundle null says that a regular neighborhood may flatten as radius grows, but it should not become steeper: a later slope increase means the neighborhood has opened into directions that were not visible locally \citep{robinson2025token}. We do not estimate the reach parameter directly. We use a conservative neighborhood range and interpret corrected slope increases as evidence that this local range is not well described by the tested regular model.

\begin{definition}[Embedded patch-token sample]
For a frozen vision encoder, the embedded sample is the finite set $Z=\{z_i\}_{i=1}^n\subset \R^\ell$ of patch-token vectors. Each $z_i$ has a source image id, a patch-grid coordinate, and a raw image patch $x_i$. Geometric tests use Euclidean distances in feature space; image patches are used for projection and sparse-reconstruction diagnostics.
\end{definition}

\begin{definition}[Empirical ball volume]
For an anchor token $z_i$ and radius $r\ge0$, the empirical volume of the feature-space ball is the neighbor count
\begin{equation}
  \widehat{V}_i(r)
  =
  \left|\{j\ne i:\|z_j-z_i\|_2\le r\}\right|.
\end{equation}
Equivalently, if $r_k(i)$ is the distance from $z_i$ to its $k$th nearest neighbor, then $\widehat{V}_i(r_k(i))=k$. Sorted distances supply the radii and sorted indices supply the empirical volumes.
\end{definition}

\paragraph{Local volume scaling.}
The dimension estimate comes from the standard small-ball volume expansion used in Riemannian geometry and intrinsic-dimension estimation \citep{gray1974volume,tenenbaum2000global,levina2005maximum,facco2017estimating}. If points are sampled near a locally $d$-dimensional set, then the volume of a small ball grows like
\begin{equation}
  \vol(B_r(z_i)) = C_i r^d + O(r^{d+1}),
\end{equation}
and the empirical count $\widehat{V}_i(r)$ approximates that local volume. Taking logs gives $\log \widehat{V}_i(r) \approx c_i + d\log r$, so the slope of a log-volume/log-radius curve estimates local dimension. In practice we do not choose radii directly. The pair $(\log r_k(i), \log k)$ traces the empirical volume curve around token $i$.

\begin{definition}[Local dimension estimate]
Given neighborhood indices $k\in[k_{\min},k_{\max}]$, the local dimension estimate at $z_i$ is the slope
\begin{equation}
  \dimhat_i = \widehat{\beta}_{1,i},
  \qquad
  \log k = \beta_{0,i}+\beta_{1,i}\log r_k(i)+\varepsilon_{k,i}.
\end{equation}
We treat $\dimhat_i$ as a local diagnostic, not as a global manifold dimension. It can vary across tokens in the same image.
\end{definition}

\begin{theorem}[Fiber-bundle slope rule, after \citet{robinson2025token}]
\label{thm:fiber-monotone}
For a local neighborhood that behaves like the fiber-bundle model in \citet{robinson2025token}, the log-volume/log-radius curve may change slope as radius grows, but the slope should stay the same or decrease. A statistically significant slope increase is therefore evidence against the fiber-bundle null.
\end{theorem}

\paragraph{Fiber violations and irregularity.}
The local dimension estimate uses one slope as a summary. The fiber test asks whether that slope changes in the direction ruled out by \Cref{thm:fiber-monotone}. We record ordinary change points when the curve changes shape, but count a fiber violation only when the later radius window is steeper than the earlier one.

\begin{definition}[Patch-token irregularity score]
For each anchor token $z_i$, we scan adjacent windows on its log-volume/log-radius curve and test only the fiber-violating direction: the later window has larger slope than the earlier window. We apply Holm-Bonferroni correction \citep{holm1979simple} to these slope-increase tests, as in \citet{robinson2025token}. Let $p_i^+$ be the smallest adjusted p-value for token $z_i$. The irregularity score is
\begin{equation}
  \irr_i =
  \begin{cases}
  -\log_{10}(p_i^+), & p_i^+<\alpha,\\
  0, & p_i^+\ge \alpha.
  \end{cases}
\end{equation}
\end{definition}

Thus $\irr_i$ is zero unless a corrected slope increase is significant; larger values mean stronger evidence for the forbidden direction. The irregular ratio is the fraction of patch tokens with $\irr_i>0$. Heatmaps project this score back to image space.

\paragraph{Local sparse complexity.}
The sparse probe asks how much raw visual variation lies inside a token neighborhood. Sparse coding and dictionary learning measure whether signals can be represented with a small number of local basis elements \citep{olshausen1996emergence,mairal2009online}. We use Orthogonal Matching Pursuit (OMP) \citep{pati1993orthogonal,tropp2007signal} because it gives an interpretable code length: the number of atoms needed to hit a fixed reconstruction error.

For the fixed-neighborhood probe, $\mathcal{N}_i$ is the set of nearest token neighbors of anchor $i$. We use $k=128$ neighbors, a 128-atom local PCA dictionary, and OMP sparsity cap 64. For each anchor, we collect the corresponding raw image patches $\{x_j:j\in\mathcal{N}_i\}$, center and normalize them, build a dictionary from the leading right singular vectors of the local patch matrix, and reconstruct each patch with OMP. The required sparsity $s_{ij}$ is the smallest support size that reaches target relative residual $\tau$, subject to the cap. The token-level sparse complexity is
\begin{equation}
  S_i=\frac{1}{|\mathcal{N}_i|}\sum_{j\in\mathcal{N}_i} s_{ij},
\end{equation}
where high $S_i$ means the token neighborhood contains raw patches that are hard to explain with a very sparse local code. We report a strict baseline $\tau=0.15$ and sweep $\tau\in\{0.15,0.20,0.25,0.30,0.35,0.40\}$ to separate regional variation from cap saturation.

We also run an expanding-neighborhood probe for the spatially middle patch token. For volumes $8,16,\ldots,512$, we take the nearest token neighborhood of that size, fit a fresh local dictionary, and rerun OMP. If required sparsity still rises, the effect is not caused by forcing all scales to share one global dictionary.

\paragraph{Reading the visualizations.}
The visualizations are part of the evidence. Fiber heatmaps project $\irr_i$ back to the source image grid. Dimension galleries show the raw patches selected as low-, middle-, high-dimension, or high-violation examples. Sparse heatmaps project $S_i$ back to image space, and middle-patch volume curves show how OMP sparsity changes as neighborhoods grow. Together they keep local feature-space scaling, corrected slope changes, and raw-patch reconstruction complexity distinct.

\section{Experimental Setup}
\paragraph{Data.}
The main experiments use \dataset{COCO} images resized to $224\times224$. The goal is not to train or rank classifiers, but to use dense image tokens as a medium for local geometric diagnostics. Patch-size-16 encoders give a $14\times14$ grid, or 196 tokens per image. AIMv2 and VAR use $16\times16$ analysis grids, or 256 tokens per image. Most \dataset{COCO} comparisons use the same 16 image-aligned examples; the DINOv3 ViT-L/16 row uses a preceding 21-image run as a scale comparison.

We run the same frozen-encoder pipeline on \dataset{STL10}, \dataset{DTD}, and \dataset{EuroSAT}. These are stress tests: \dataset{STL10} gives object-centered images, \dataset{DTD} emphasizes textures, and \dataset{EuroSAT} gives satellite scenes. SAM runs outside \dataset{COCO} use frozen image-encoder patch tokens only, without box prompts or mask previews.

\paragraph{Models for Evaluation.}
We use ViT-style checkpoints because they expose one vector per image patch \citep{dosovitskiy2021image}. DINOv3 provides strong self-supervised visual features \citep{simeoni2025dinov3}; SAM provides segmentation-oriented encoder tokens and COCO mask previews for context \citep{kirillov2023segment}; SigLIP2 and AIMv2 test modern multimodal dense encoders \citep{tschannen2025siglip2,elnouby2024aimv2}; VAR-d30 is an auxiliary autoregressive visual-token generator rather than a matched encoder baseline \citep{tian2024visual}. All geometry and sparse probes use frozen representations. Table~\ref{tab:checkpoint-settings} gives the exact checkpoints and settings.

Neighborhood locality shows what the volume-growth test is sampling. DINOv3 is extremely image-local, with DINOv3-L/H+ mean same-image neighbor fractions of 0.985 and 0.979. SAM-H is less image-local (0.659) but still 10.6$\times$ above chance. SigLIP2-B and AIMv2-L remain far above chance while mixing more than DINOv3. VAR-d30 is qualitatively different, with same-image fraction 0.143, consistent with a generation-token space rather than a frozen encoder neighborhood.

Same-image locality does not say whether token distances preserve raw-patch distances inside an image. We therefore also compare the pairwise distance matrix of raw RGB patches with the pairwise distance matrix of the corresponding model tokens; details and visualizations are in \Cref{app:patch-token-distance}. This diagnostic asks how much the learned feature metric warps the image's original patch geometry. A high score means that patches near an anchor in raw RGB space also tend to be near it in token space. A low score does not mean failure: it can mean that the representation has reorganized patches according to semantics, context, segmentation cues, or invariances that are not visible in raw pixel distance. In the current \dataset{COCO} runs, SAM-H preserves more within-image raw-patch distance structure than DINOv3-H+, while SigLIP2-B and AIMv2-L move furthest away from raw RGB patch geometry.

The sparse probe asks whether feature-space neighborhoods also contain simple raw visual neighborhoods. We use the higher-capacity $k=128$ setting because the initial $k=32$ probe was too capacity-limited for SAM. If neighborhoods remain hard under this setting, they are not hard merely because the dictionary is tiny.

\section{Discussion}
Dense vision representations let us test stratified geometry at patch resolution. Each token is both a point in representation space and a visible region in an image, which lets us separate facts that a global intrinsic-dimension estimate would collapse.

The core pattern is stable. DINOv3 and SAM have similar median local dimension on \dataset{COCO}, but differ in same-image locality and slope-change structure. SigLIP2 and AIMv2 move the comparison into a higher-dimensional regime while preserving strong locality. Cross-dataset probes show that the diagnostic changes with visual domain: \dataset{DTD} is sparse-simple for several encoders but not SAM, while \dataset{EuroSAT} makes SAM's corrected fiber violations and sparse burden stand out. A generic change point is not the same as a fiber violation, and sparse raw-patch reconstruction is not the same as local dimension. The VAR-d30 probe adds a useful caution: generation uncertainty aligns more with broad local dimension than with corrected fiber violations.

The restrained claim is enough: modern pretrained vision checkpoints exhibit heterogeneous local geometry, so a single global dimension estimate is a poor summary. This is a diagnostic case study of stratified structure in dense vision spaces, not a final benchmark over all vision models or domains.

\section{Limitations}
The study is intentionally small. The main comparison uses 16 image-aligned \dataset{COCO} images and a limited set of large pretrained checkpoints; the \dataset{STL10}, \dataset{DTD}, and \dataset{EuroSAT} runs are stress tests, not benchmark-scale studies; and VAR-d30 is auxiliary rather than a matched encoder baseline. The local dimension estimator depends on neighborhood range, distance metric, smoothing, and multiple-testing correction. The sparse dictionary probe depends on dictionary size, sparsity cap, and residual threshold. SAM masks provide useful context on \dataset{COCO}, but the fiber statistics are computed from encoder tokens rather than mask quality; outside detection datasets, SAM should be read only as a frozen encoder. A stronger version should scale the image count, compare more checkpoints and datasets, calibrate the change-point test with stronger null controls, and compare against alternative intrinsic-dimension estimators \citep{facco2017estimating}.

\section{Conclusion}
Vision is a dense, spatially grounded medium for the stratified-manifold question raised by language-token embeddings. Across \dataset{COCO}, \dataset{STL10}, \dataset{DTD}, and \dataset{EuroSAT}, frozen DINOv3, SAM, SigLIP2, and AIMv2 patch-token spaces are not well summarized by one global intrinsic dimension. The useful story is local: dimension estimates, fiber-violation maps, sparse-complexity heatmaps, patch--token distance diagnostics, and SAM mask previews together reveal stratified structure that a single number would hide.
