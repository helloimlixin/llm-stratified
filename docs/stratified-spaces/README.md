# Stratified Spaces Paper Bundle

This folder contains the NeurIPS paper workspace for the stratified-spaces project.

## Contents

- `main.tex`: self-contained anonymous submission source using vendored figures in `../imgs/neurips_submission/`.
- `draft.tex`: preprint-style draft that points at the full external run artifacts.
- `outline.tex`: longer outline/skeleton for extending the paper.
- `refs.bib`: shared bibliography for all paper variants.
- `neurips_2026.sty`: NeurIPS style file used by the TeX sources.
- `checklist.tex`: NeurIPS checklist included by the TeX sources.
- `framing.md`: framing note for the stratified-space interpretation.
- `../imgs/neurips_submission/`: vendored figure assets used by the anonymous submission source.
